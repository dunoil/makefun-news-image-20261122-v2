A one-image broadsheet summing up the world news of Sunday 22 November 2026, built for the make.fun bounty "Sum up 22 November's world news in one image" ($100 in prizes, $20 for 1st place). It carries 35 stories across 7 regions: 3 lead cards, 10 smaller illustrated cards, and 22 one-line briefs, plus a numbers strip, a region bar, a world map with numbered pins, and a DATE CHECK footer naming five prior-day stories that are excluded.

`render.py` draws the image with Pillow; `main.ts` copies the rendered `entry.png` to the output directory after checking it is a whole PNG inside the gate limits.
